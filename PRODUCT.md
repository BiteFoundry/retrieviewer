# Retrieviewer

BiteFoundry's autonomous monochrome Unicode Braille retriever companion.
The default desktop experience is a separate transparent native window that
follows one user-selected app window. Users offer a treat or toss a ball; the
puppy otherwise roams and rests. No account, inference API or telemetry is needed
by the runtime. This is authored behavior, not a sentience claim.

The approved fluffy Q5 artwork, proportions, fixed-camera perspective and grounded
movement are product identity. Do not replace them with generic 3D/voxel art.
Code is MIT; art is CC BY-SA4.0 with retained attribution. Do not conflate them.

Install guide: at most two primary steps: global npm install, then desktop launch.
Show prerequisites separately. Remote SSH users install where the app window is
displayed, not blindly on the remote host. npx is a one-off alternative, not PATH setup.
Windows is live tested. Linux means a composited X11 desktop, including a tested
Alma8/GLIBC2.28 baseline. macOS is experimental and not runtime verified. No native
Wayland overlay. Low-resource defaults are not a zero-memory/CPU promise.

Website: English/Korean buttons, existing black/white dot-art identity, real
runtime demonstration and clear two-step install. LinkedIn: Korean-first with
brief English summary. No publishing to social accounts without explicit request.

## Purrviewer ginger cat

The existing website also introduces the approved ginger Purrviewer cat before
installation, with a short link from the hero. The package also supports
`retrieviewer desktop --pet cat`, with species selection in the Windows basic
engine. The browser demo uses a pinned Purrviewer runtime and a `SOURCE.json`
file manifest. Preserve the retriever's separate demo and two-step install flow.
The static poster comes from the actual canvas scene. Starting the demo lazily
loads one live canvas and its cat artwork; it does not autoplay. There are five
cat interactions: slow blink, offer a treat, keep me company, cat tower and
exercise wheel, plus Start, Pause / Resume and Full screen controls. Loading,
retry, unsupported-browser, paused and fullscreen-unavailable feedback follow the
existing EN/KO document language.

The canvas backing area is capped at one million pixels. The scheduler targets
8 fps at rest and 30 fps during action, suspends while hidden or offscreen,
pauses for bfcache navigation and resumes on return, and disposes the runtime on
final page exit. These are implementation bounds, not RAM or performance
guarantees. The cat's scoped amber accent does not replace the site's Leaf roles.

selected by the owner on2026-10-25. Keep the separate cat credits and artwork
terms linked from its section.
